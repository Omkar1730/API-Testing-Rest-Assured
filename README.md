# REST Assured API Automation Framework

This is a scalable and modular API automation framework built from scratch using REST Assured, Java, TestNG, and Maven.

## 🚀 Key Features
- Clean and maintainable framework design
- Reusable request specifications
- Support for GET, POST, PUT, DELETE APIs
- Centralized configuration management
- TestNG-based execution and assertions
- Designed with scalability and extensibility in mind

## 🛠 Tech Stack
- Java
- REST Assured
- TestNG
- Maven

## 📂 Project Structure
- base → Common setup and configurations
- tests → Test classes
- utils → Helper utilities
- models → Request/Response POJOs

## 🎯 Goal
The goal of this project is to demonstrate strong understanding of API automation fundamentals and framework design principles suitable for real-world applications.
